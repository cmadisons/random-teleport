# 2do

~~in the same mod make sheep have different colours wool and look different
colours~~ **done** — every sheep that spawns gets one of the sixteen dyes,
picked evenly, instead of vanilla's roughly-82%-white table. Lambs are left
alone so breeding for colour still works, and each sheep is marked once it has
been painted so it does not change colour every time the chunk reloads.
